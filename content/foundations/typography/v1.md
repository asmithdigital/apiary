Typography defines the visual voice of our products, balancing accessibility, hierarchy, and style to support clear, consistent communication across platforms.

Apiary provides a comprehensive set of typography styles defined by visual properties such as font size, weight, line height, and letter spacing. The design system does not prescribe specific HTML elements (like &lt;h1&gt;, &lt;p&gt;), as the correct semantic structure depends on the component's context and page hierarchy. This approach allows teams to maintain both visual consistency and semantic accessibility. As body text styles vary between applications, this page focuses on the visual style definitions rather than fixed HTML element assignments.

## Weights and sizes

The typography styles support clear hierarchy and emphasis by providing a flexible range of font weights and sizes.

- Extra Bold — 42px/48px, 36px/42px, 30px/36px, 24px/30px (font size / line height)
- Bold — available from 42px down to 12px, each with matching line heights
- Medium, Regular, Underline — available in sizes from 42px to 12px with matching line heights

## Usage guidelines

- Use typography styles to clearly communicate hierarchy and meaning without relying solely on font size or weight
- Choose semantic HTML heading levels based on content structure, not visual appearance
- Body text styles may differ between applications — refer to specific app guidelines when needed
- Ensure text contrast meets accessibility standards for legibility
- Use underline styles sparingly, primarily for links or subtle emphasis, to avoid confusing users
