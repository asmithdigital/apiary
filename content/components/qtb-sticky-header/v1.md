The header sits at the top of the page and provides quick access to navigation, branding, and key actions like search or user profile. It should be consistent, responsive, and accessible across all devices.

## Anatomy

- Header — logo, section title, flexible space, "Need help" label, help icon
- QTB Header — price, billing info, spacer/alignment zone, call-to-action button

## Size

- Logo-to-title gap — spacing-md (~24px)
- "Need help" text-to-icon gap — spacing-sm (~8px)
- Help icon to Log out button gap — spacing-md
- Log out button padding — 12px vertical, 24px horizontal
- QTB header — spacing-md left/right, spacing-sm price-to-description, spacing-md top/bottom

## Typography

- Title — Bold/16px | 22px
- "Need help" text — Bold/14px | 20px
- Help icon — Font Awesome 14px | 20px
- "Log out" CTA — Bold/14px | 20px
- QTB price — Bold/36px | 40px; "per month" Bold/14px|20px; "or $X per year" Regular/14px|20px

## Behaviour

- "Saving..." / "Saved just now" give real-time autosave feedback, removing the need for a manual Save button — may fade after a few seconds or stay subtly visible

## Accessibility

- Fully keyboard navigable with screen reader support and sufficient colour contrast
- Clear focus states and descriptive aria-labels on interactive elements
- Logo links to the homepage with alt text
- Use navigation landmarks (&lt;header&gt;, role="banner")

<div class="apy-do">

**Do**

- Keep the header responsive across screen sizes
- Use semantic HTML/ARIA roles
- Provide meaningful alt text for the logo
- Maintain consistent layout and hierarchy across pages

</div>

<div class="apy-dont">

**Don't**

- Overload the header with too many actions or links
- Use non-descriptive labels/icons without alternatives
- Rely solely on colour to convey information
- Hide critical navigation on small screens without an accessible alternative

</div>
