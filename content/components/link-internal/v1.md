Links are used as navigational elements. They navigate users to another location, such as a different site, resource, or section within the same page.

## When to use

- Open related material (like information drawers or documents)
- Expand content
- Navigate to an entirely different site
- Jump to an element on the same page
- Link to emails or phone numbers

## Variants

- Confirmed on a second real pass as four types: Internal link, External link, Back link, Information link — the first pass's longer list (download link, comparison table link, etc.) may be older/broader; treating this shorter list as the current canonical set.

## Anatomy

- A link always includes link text and can have an icon.
- 1. Link text, 2. Icon (optional)

## Size

- Keep links large enough to interact with — link targets should be at least 24×24px

## Typography

- Label — National 2 Underline/14px | 20px, Interaction/Link
- Icon — Font Awesome 6 Pro Regular/14px | 20px, Interaction/Link

## Character limit

- See Do/Don't for guidance on link length

## States

- Default, focus, hover, active, visited

## Transitions

- Animation on hover and click

## Arrangement & spacing

- Links with an icon: used on their own or directly following content. Align the icon to the text baseline when it spans more than one line. 6px spacing between text and icon.
- In-text link: used within a sentence or paragraph — should not be paired with an icon.

## Accessibility

- Open links in a new tab when there's a risk of someone losing their current place or task (e.g. insurance QTB journeys), or when the link takes them out of the current product / to an external site
- Include an external link icon for standalone links for sighted users, and provide a visually hidden warning for screen readers
- Links must be keyboard-navigable, receive focus when tabbed to, and have a clear focus state

<div class="apy-do">

**Do**

- Ensure link text is descriptive and meaningful, understandable even out of context
- Specify if a link triggers a download, including file type and size
- Only include a verb in the linked text if it better describes the purpose or differentiates it from other links/actions
- Maintain consistent styling (underlines, colour changes) so links are easily distinguishable

</div>

<div class="apy-dont">

**Don't**

- Confuse links and buttons
- Use vague phrases like "Click here" or the URL as link text
- Repeat the same link text over and over on a page
- Include unnecessary links — too many can overwhelm a page, particularly for screen reader users
- Create circular links that may frustrate or disorient the user

</div>
