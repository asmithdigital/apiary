A lozenge is a visual indicator used to highlight an item's status for quick recognition.

## Size

- Padding top & bottom — 2pt
- Padding left & right — spacing/xs
- Gap — 4pt
- Default max width — 200px, truncates with an ellipsis past that; customisable via a maxWidth property

## Typography

- Label — National 2 Medium/12px | 18px
- Leading icon — Font Awesome 6 Pro/12px | 18px

## Types

<dl class="apy-deflist">
<dt>Primary</dt><dd>Used for the most important call to action.</dd>
<dt>Secondary</dt><dd>Used for secondary actions.</dd>
<dt>Tertiary</dt><dd>Used for passive actions.</dd>
</dl>

## Accessibility

- Don't use colour alone to signify an important state — use an accurate label too (e.g. "Error" or "Warning" for a critical status)
- Don't use lozenges for long text — they aren't focusable, so any text truncated past 200px (or a custom maxWidth) won't be accessible
