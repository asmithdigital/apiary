A lozenge is a visual indicator used to highlight an item's status for quick recognition.

## Size

- Padding top & bottom — 2pt
- Padding left & right — spacing/xs
- Gap — 4pt
- Default max width — 200px, truncates with an ellipsis past that; customisable via a maxWidth property

## Typography

- Label — National 2 Medium/12px | 18px
- Leading icon — Font Awesome 6 Pro/12px | 18px

## Types

**Primary** — Used for the most important call to action.

**Secondary** — Used for secondary actions.

**Tertiary** — Used for passive actions.

## Accessibility

- Don't use colour alone to signify an important state — use an accurate label too (e.g. "Error" or "Warning" for a critical status)
- Don't use lozenges for long text — they aren't focusable, so any text truncated past 200px (or a custom maxWidth) won't be accessible

<div class="apy-do">

**Do**

- Use a single, purposeful icon when it enhances meaning or scan-ability, with a clear semantic relationship to the text
- Include a text label always, unless the icon is universally recognised and accessible on its own
- Use concise text so the lozenge stays readable and accessible

</div>

<div class="apy-dont">

**Don't**

- Use multiple icons — this confuses users about the lozenge's function
- Use an icon purely for decoration
- Let text truncate — truncated text can't be focused or read by assistive technology

</div>
