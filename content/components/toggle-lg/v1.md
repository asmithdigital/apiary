Toggles are used to switch between two mutually exclusive states, "on" and "off", and are best suited to system and settings functionality (e.g. enabling windscreen coverage for an insurance policy, or turning on account notifications).

## Variants

- Toggle (Desktop) — default size, optimised for cursor interactions
- Toggle LG (Mobile) — larger touch target for improved accessibility on touch devices

## Anatomy

- Track — the background path, indicating on/off state via colour
- Thumb — the handle the user interacts with
- Icon — a check or cross icon indicating the on/off state

## Size

- Toggle — 40px width, 20px height, 16px thumb
- Toggle LG — 60px width, 30px height, 26px thumb

## Typography

- Font Awesome Pro for the state icons — Toggle Regular/12px, P3/100 (default/focus), P2/30 (disabled); Toggle LG Regular/14px, same colours

## States

- Default — shows current state
- Focus — visible focus ring/highlight on keyboard navigation
- Disabled — dimmed, non-interactive

## Transitions

- Smooth thumb movement between positions
- Timing TBC, e.g. 200ms ease-in-out
- Track colour fades to match the new state

## Accessibility

- Use role="switch" for semantic clarity
- Include aria-checked="true/false"
- Labels clearly associated via &lt;label for="id"&gt;
- Sufficient colour contrast for both states
- Focus states visible and meeting contrast requirements
