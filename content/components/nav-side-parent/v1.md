Navigation in a design system includes reusable components like headers, sidebars, and menus that help users move through an interface easily. It ensures consistency, supports wayfinding, and defines behaviour across devices. RAA's navigation is clear, responsive, and structured — primary links with icons, optional sub-navigation, and active state highlights, adapting to a collapsible menu on mobile.

## Anatomy

- 1. Parent Menu Icon, 2. Parent Menu Item (Expanded), 3. Parent Menu Item (Collapsed), 4. Parent Menu Item (Default), 5. Menu Group Container, 6. Expand/Collapse Icon, 7. Child Menu Items
- Side drawer: 1. Close Button, 2. Log Out Button — the rest is the same as the standard side nav

## Typography

- Menu parent icon — Font Awesome 6 Pro/18px | 24px
- Menu child text — Regular/12px | 20px
- Menu parent text — Bold/16px | 22px
- Menu open/close icon — Font Awesome 6 Pro/16px | 22px

## Behaviour

- Menus open and close with a subtle, responsive animation — 200–300ms, ease-in-out. Expanding: child items fade and slide down slightly. Collapsing reverses this motion, avoiding abrupt changes.

## Types

**Navigation** — Provides clear access to key sections with top-level items and optional submenus. Icons sit 8px from labels, with consistent vertical spacing and 24px side padding. Items are vertically aligned, touch-friendly, and keyboard accessible.

**Navigation side** — Side navigation anchors the layout with a vertical menu. Parent items expand to show indented child links. Spacing is consistent for readability, supporting clear hierarchy, responsiveness, and accessibility.

## Accessibility

- Fully accessible for assistive technology users — each menu item is keyboard navigable with clear focus states
- Expandable sections use aria-expanded and aria-controls to convey state to screen readers
- Icons are paired with descriptive labels so meaning is conveyed both visually and audibly
- Close and logout buttons are easily reachable with descriptive aria-labels
- All interactive elements follow a logical tab order

## Content guidelines

**Be consistent across platforms** — Keep placement, behaviour, and styling consistent across devices to reduce cognitive effort.

**Prioritise clarity over cleverness** — Use simple, recognisable labels — avoid jargon or playful ambiguity.

**Limit primary navigation items** — Keep top-level navigation to 5–7 core items; use secondary/mega menus for deeper structures.

**Use visual hierarchy to show relationships** — Indentation, font weight, size, or spacing to differentiate parent items from sub-items.

**Ensure responsive behaviour** — Hamburger menus, bottom nav bars, or collapsible drawers on small screens; full navigation on larger ones.

**Highlight the current location** — Bold text, underlines, selected states, or breadcrumb trails so users know where they are.

**Use descriptive icons with labels** — Icons speed recognition but should be paired with text unless universally understood (e.g. a house icon for "Home").

## Real token names (documentation)

- Top padding of container — spacing/md
- Top margin to first item — spacing/lg
- Gap between menu groups — spacing/md
- Bottom margin below last item — spacing/lg
- Left/right padding of container — spacing/sm
- Side drawer — spacing/md padding top (close icon), spacing/sm padding top (log out button)
