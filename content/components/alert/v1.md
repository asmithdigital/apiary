To attract a user's attention with important messages or required actions.

## Variants

- Size: Standard, Mini, Mobile, Mini mobile
- Information — general information
- Confirmation — confirms an action or success
- Warning — a minor warning
- Error — a critical error has occurred
- Change — a tip or non-critical change

## Anatomy

- Container — wraps the content
- Icon — supports the variant meaning (circle-info / circle-check / triangle-exclamation / circle-exclamation / lightbulb)
- Title — conveys what triggered the alert
- Description (optional) — purpose and next steps, can include in-text links
- Dismissal (optional) — permanently removes the alert
- Actions (optional) — links to remedy the alert or continue a task

## Size

- Standard: 24px padding, 24px between things, 6px between text
- Mini: 12–18px padding, 12px between things, 6px between text
- Mobile: 24px padding, 12px between things, 6px between text
- Mini mobile: 12–18px padding, 12px between things, 6px between text
- All fill container width, hug content height

## Typography

- Standard & mobile — Title Bold/16px|22px P2/100; Description Regular/14px|20px P2/100; Actions Underline/14px|20px Interaction/Link; Icon FA6 Pro Regular 24px P2/100; Dismiss FA6 Pro Solid 14px P2/60.
- Mini & mini mobile — Title Medium/14px|20px P2/100; Actions Underline/14px|20px Interaction/Link; Icon FA6 Pro Regular 18px P2/100; Dismiss FA6 Pro Solid 14px P2/60.

## Character limit

- Standard & mobile: under 60 characters should use the mini variant instead
- Mini & mini mobile: 60 character limit

## States

- Skeleton — shown while the component is loading

## Transitions

- Animation on skeleton load, then transitions into the real alert type

## Priority

- Alerts appear in priority order: 1. Error, 2. Warning, 3. Information, 4. Change

## Accessibility

- Actions and dismiss button must be focusable
- Don't rely on colour alone — provide an accessible label for the type/icon
- Dynamic alerts should use the alert role (a live region that doesn't take focus)
- Minimum touch target 48×48px for actions and dismiss
- No fixed height — text must be able to zoom/resize

## Do

- Make error messages clear and concise
- Use the correct variant for the content length and device

## Don't

- Restyle with other colours or icons
- Use multiple icons
- Use buttons instead of links for actions
- Write too much
- Change the icon
- Use a basic alert without a description
- Use a mini alert without a description
