A section title clearly indicates the beginning of a new content group within a page or interface. It helps users quickly understand the topic or purpose of the section, improving content scanability and accessibility. Typically styled with larger or bold typography, section titles establish visual hierarchy and support content structure across different screen sizes.

## Anatomy

- The text label (defining the section's purpose), typography (larger size, bold weight), spacing (padding/margin for separation), alignment (usually left-aligned), and sometimes a supporting icon or divider.
- 1. Title/Header

## Typography

- Title/Header — Bold/16px | 22px

## Types

**Primary section title** — Currently the only type — bold, large, and highly visible to help users quickly identify main content areas. Provides clear structure and hierarchy for scanning and accessibility. Should be styled consistently across pages, using language that reflects the content that follows so both users and screen readers understand the page's layout.

## Accessibility

- Use a semantic <h2> heading to convey structure to assistive technologies
- Follow a logical heading order — never skip levels
- Sufficient colour contrast; hierarchy must be programmatically determinable, not just visual

## Do

- Use semantic heading tags for proper structure
- Keep titles short, descriptive, and meaningful
- Maintain visual consistency in typography, size, and spacing
- Ensure sufficient colour contrast

## Don't

- Use visual style alone (size/colour) to indicate importance without semantic markup
- Skip heading levels (e.g. <h2> straight to <h4>)
- Use vague or generic labels like "Section 1"
- Use all-caps unless stylistically necessary and still readable
- Place interactive elements inside section titles unless clearly labelled and accessible

## Content guidelines

**Text and contents** — Concise and descriptive (ideally 1–5 words); consistent title/sentence case; avoid vague terms like "Content Area".

**Structure and semantics** — Semantic heading tags, no skipped levels; only one <h1> per page, with section titles starting at <h2>.

**Visual style** — Larger, bolder than body text; adequate spacing above/below; left-aligned unless the layout requires otherwise; dividers/icons only if they support clarity.
