The select option lets users choose one item from a dropdown list. It includes a label, a dropdown icon, and a list of clear, concise options. It supports keyboard navigation, focus states, and screen readers for full accessibility.

## Anatomy

- A label describing the field, a selected value area showing the chosen option or placeholder, and a dropdown icon indicating expandability. When opened, a dropdown menu shows selectable options. Optional helper text or error messages appear below.
- 1. Field label, 2. Select option, 3. Pull-down icon
- Option states: 1. Option not selected, 2. Option selected, 3. Option component

## Accessibility

- Clear, associated label for screen readers
- Semantic &lt;select&gt;/&lt;option&gt;, or ARIA combobox/listbox/option roles for custom components
- Keyboard navigation for opening the menu, moving between options, and selecting
- Visible focus indicators; all states (hover, focus, selected, error) meet WCAG AA contrast
- Error messages and helper text connected via aria-describedby

## Content guidelines

**Use clear, descriptive labels** — Users should immediately understand what they're selecting.

**Keep option text short and scannable** — Especially important on mobile.

**Order options logically** — Alphabetically, numerically, or by relevance.

**Use placeholder text thoughtfully** — e.g. "Select an option" — never as a permanent value.

**Avoid ambiguous options** — Avoid vague terms like "Other" unless followed by clarification.

**Group related options clearly** — Use headings or separators for long lists.

**Provide additional context when needed** — Tooltips or help text for options needing explanation.

**Match terms to user language** — Avoid internal jargon.

**Be consistent across the product** — Same terminology and ordering everywhere select fields appear.

**Support accessibility in wording** — Option text should make sense read aloud by a screen reader.

## Real token names (documentation)

- Label to field spacing — spacing/sm
- Padding inside input — spacing/sm (top/bottom/right), spacing/2xl+ (left)
- Option top/bottom padding — spacing/sm
- Gap option to input component — spacing/xs
