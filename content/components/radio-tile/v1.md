Radio Tiles are a stylised version of radio buttons that let users choose one option from a set. Each option appears as a clickable card or tile, often with text, icons, or images, and highlights visually when selected. They're ideal for mobile and visually rich interfaces.

## Anatomy

- Radio Tiles present one selectable option per tile in a visual, tile-based layout, supporting titles, descriptions, or icons. Only one tile can be selected at a time, with clear states for hover, focus, and selection.
- 1. Radio Button, 2. Thumbnail/Image Placeholder, 3. Title

## States

- Default — unselected, radio button, optional image/icon, and title, with a neutral border
- Clicked/Selected — the radio button fills and the tile border turns green as confirmation
- Disabled — non-interactive, dimmed/faded, cannot be selected
- Focus — a clear focus indicator (outline or border glow) on keyboard/assistive-tech focus
- Error — border or radio highlighted in an error colour (usually red), with an optional nearby error message

## Accessibility

- Use role="radio" within a radiogroup, with aria-checked to indicate selection
- Include a clear group label via aria-label or aria-labelledby
- Fully keyboard-navigable with arrow keys, with a visible focus indicator
- Minimum tap target 44×44px; the whole tile should be clickable, not just the radio input
- WCAG colour contrast; selection must never rely on colour alone

## Content guidelines

<dl class="apy-deflist">
<dt>Use clear and descriptive titles</dt><dd>The title is the primary decision-making cue — avoid vague terms like "Standard" or "Option 1".</dd>
<dt>Keep content concise and scannable</dt><dd>Short sentences or phrases, most important info first.</dd>
<dt>Support with optional subtext only when needed</dt><dd>Clarify distinctions like price tiers or durations, only if essential.</dd>
<dt>Use visuals to reinforce, not replace, text</dt><dd>Icons/thumbnails help recognition but must be paired with meaningful text.</dd>
<dt>Avoid jargon and technical language</dt><dd>Rephrase internal/business terms into plain, user-friendly language.</dd>
<dt>Ensure consistency across tiles</dt><dd>Same structure — title, optional subtext, visual position — across a group.</dd>
<dt>Use parallel sentence structure</dt><dd>If one tile starts with a verb, the others should too.</dd>
<dt>Keep tone neutral and informative</dt><dd>Radio Tiles are decision tools, not promotional banners.</dd>
<dt>Limit content per tile to one clear message</dt><dd>One core idea or value proposition per tile.</dd>
<dt>Test on multiple screen sizes</dt><dd>Avoid awkward wrapping or truncation; set max character limits where needed.</dd>
</dl>

## Real token names (documentation)

- Gap between image and title — spacing-md
- Bottom padding — spacing-lg
- Left/right padding (outer) — spacing-xl
