Users can enter text shorter than a single line. Input fields can have multiple input types depending on the use case: text, tel (phone number), email, number (postcode, bank details), or password (input obscured as the user types).

## Variants

- Default, value, invalid, valid, icon left, icon right

## Anatomy

- Label
- Container
- Text (optional)
- Prefix icon (optional)
- Suffix icon (optional)
- Description (optional)

## Size

- 6px spacing between label, container and description
- 12px padding in the container
- 12px between icons and text
- Container minimum 44×44px

## Typography

- Label — Medium/14px | 20px, P2/100
- Text — Regular/14px | 20px, P2/100
- Description — Regular/12px | 18px, P2/50
- Icon — Font Awesome 6 Pro Regular 24px, P2/100
- Invalid: Invalid/100. Valid: Valid/100. Disabled: P2/40.

## Character limit

- Single line, no truncation — make it scrollable or use a text area for long input

## States

- Default, active, hover, focus, disabled

## Transitions

- Animation on active and focus states

## Arrangement & spacing

- 24px margin between input fields and nearby components
- Field width should match how much information is needed
- Inline layout for side-by-side fields on larger screens; full width on mobile

## Accessibility

- Avoid placeholder text where possible — it disappears once typing starts, isn't always read by screen readers, and often lacks contrast
- Use prefixes/suffixes for things like currency, but don't rely on them alone — say the format in the label/hint text too
- Enable autocomplete wherever possible

<div class="apy-do">

**Do**

- Always use a label
- Use the prefix for measurements/categories (e.g. '$')
- Pair the prefix with hint text (e.g. 'Cost, in dollars')
- Match the input type to the data (e.g. type="tel")
- Announce inline validation errors and focus the field in error
- Give specific error messages that explain the fix
- Communicate expected format and validate it
- Keep tab order logical

</div>

<div class="apy-dont">

**Don't**

- Use an input field without a label
- Use an asterisk for mandatory/optional — write '(optional)' instead
- Use placeholder text
- Truncate text
- Disable copy and paste
- Hijack the cursor during input
- Use placeholder text for instructions
- Write error messages that don't explain the fix

</div>
