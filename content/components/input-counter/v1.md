An input counter shows the number of characters entered, or lets a user increment/decrement a numeric value, helping them stay within a set limit (e.g. "16 / 99"). It updates in real time and may show a warning when a limit is exceeded.

## Anatomy

- Decrement button (−)
- Value display (current number)
- Increment button (+)

## Accessibility

- Operable by keyboard and screen readers
- Each button needs a clear aria-label ('Increase value' / 'Decrease value')
- Current value exposed via an aria-live region or a labelled editable input
- Visible focus indicators, minimum touch target 44×44px
- Use role="spinbutton" with aria-valuenow/aria-valuemin/aria-valuemax
