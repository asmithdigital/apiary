The accordion component is used to organise and display content in collapsible sections. It allows users to toggle the visibility of content areas, helping manage dense information and reduce cognitive load.

## Variants

- Basic — for simple sections and grouped content, e.g. driver details or FAQ
- Detailed — for complex content or multiple levels of information, e.g. policy details

## Anatomy

- Basic — Border, Background surface, Label, Icon (closed); when open: Content zone, Divider, Icon (open)
- Detailed — Border, Lozenge component, Icon (closed), Large vector icon, Label, Heading; when open: Content zone, Icon (open)

## Size

- Basic — padding top/bottom spacing-md, padding left/right spacing-md, gap spacing-md (open: content padding top/bottom spacing-md, left/right spacing-md)
- Detailed — padding top/bottom spacing-md, left/right spacing-md, image-to-content gap spacing-md, icon gap spacing-md, lozenge-to-content gap spacing-xs (open: content padding top/bottom spacing-md, left/right spacing-md)
- Touch target at least 44×44px on mobile

## Typography

- Titles — National 2 Bold/16px | 22px, P2/100
- Headings — National 2 Bold/14px | 20px, P2/100
- Content — National 2 Regular/14px | 20px, P2/100

## Character limit

- Titles — maximum 60 characters (avoid truncation on small screens)
- Headings — maximum 60 characters (depending on variant)
- Content — should fit within 3–5 paragraphs; break large blocks into multiple accordion items

## States

- Default — collapsed, click to expand
- Hover — container highlights to indicate interactivity
- Focus — visible focus ring for keyboard navigation
- Active (table) — content fully revealed, table format
- Active (basic content) — paragraph format
- Active (custom content) — customisable format
- Skeleton (closed)
- Skeleton (open)

## Accessibility

- Use a semantic <button> for triggers
- Apply aria-expanded="true/false" to indicate state
- Group accordion content with aria-controls and id
- Ensure content is focusable and screen-reader friendly
- Keyboard: Tab between headers, Enter/Space to toggle

## Do

- Present large amounts of related information in a compact space
- Use meaningful, concise titles
- Group related content logically
- Ensure visual indicators match the state

## Don't

- Use when all information must be visible at once
- Use when the content is critical for completing a task
- Use when the expanded content is very short
- Nest accordions within accordions
- Use as a substitute for page navigation
- Hide essential information users must always see
