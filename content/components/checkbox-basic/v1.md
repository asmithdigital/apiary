Checkboxes allow users to select one or multiple options from a list. They are ideal for toggling individual features on or off, or for selecting multiple items for bulk actions.

## Variants

- Basic — simple forms or single-item selections
- Checkbox List (Vertical) — filtering lists, multi-select menus
- Checkbox (Horizontal) — grouping options, e.g. inside cards or tiles
- Checkbox Horizontal (Mobile) — mobile-friendly selection

## Anatomy

- Checkbox input — clickable control showing checked/unchecked state
- Label — beside the checkbox
- Count (optional) — indicates quantities of list items
- Container (optional) — visual boundary

## Size

- Container padding — vertical 6px / horizontal 2px
- Vertical spacing between list items — 12px
- Checkbox size — 20×20px
- Minimum height 32px (excluding optional container)
- Touch target at least 44×44px on mobile

## Typography

- Label — National 2 Regular/14px | 20px, P2/100

## Character limit

- Labels — maximum 50 characters
- Count — numeric, avoid long strings

## States

- Default — unchecked
- Hover — [behaviour TBC]
- Focus — visible focus ring
- Pressed
- Selected — filled with checkmark
- Disabled (checked)
- Disabled (unchecked)
- Invalid — error text

## Transitions

- Smooth transitions [time duration TBC]

## Arrangement & spacing

- Basic — icon 16×16px, icon padding 2px, gap 12px
- Horizontal — padding 12px all sides
- List — padding 6px vertical / 2px horizontal, gap 12px

## Accessibility

- The clickable area must include both the checkbox and its label
- Use native &lt;input type="checkbox"&gt; where possible
- aria-checked="true/false" on custom checkboxes
- aria-invalid="true" for error states
- Proper label association via &lt;label for="id"&gt;
- Minimum touch target 44×44px including padding
