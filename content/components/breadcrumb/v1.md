The Breadcrumbs component provides users with contextual information about their location within a product's hierarchy. It improves navigation, particularly on deep pages, and reduces the need for backtracking by offering quick access to previous levels.

## Variants

- Primary — plain text with separators (e.g. "My Account home / My Road Service / Road Service details")
- With icons — leading icons to improve scannability
- Overflow — collapses intermediate items into a dropdown when space is limited
- Current page is non-clickable by default

## Anatomy

- Container — horizontal flex container
- Items — each breadcrumb item, typically a text link
- Separator — plain text with /
- Current item — last item on the right, styled distinctly and not clickable

## Size

- Padding — recommended 8px top/bottom, 16px left/right minimum
- Margin — optional vertical spacing (e.g. 24px)
- Width — responsive, fits container or truncates with overflow logic
- Collapses on mobile to save space

## Typography

- Primary and sub item — Underline/14px | 20px, P2/100
- Current item — Regular/14px | 20px
- Icon — Font Awesome 6 Pro/14px | 20px, P2/100
- Should scale dynamically with accessibility settings or screen size

## Character limit

- Recommended 20–24 characters per item
- If exceeded, truncate with an ellipsis, with full text accessible via tooltip or an alternative method

## States

- Default, hover, focus, active/pressed, disabled, selected

## Transitions

- Fade or slide animations between states
- Duration 150–300ms depending on interaction
- Consistent easing (e.g. ease-in-out)

## Arrangement & spacing

- Left-aligned, consistent spacing between elements
- On small screens, prioritise essential content and reduce horizontal padding

## Accessibility

- Keyboard navigable — reachable via Tab
- Use aria-current, aria-disabled, aria-label appropriately
- Meets WCAG AA colour contrast (4.5:1 minimum)
- Visible focus indicators
- Layout must not break at up to 200% zoom

## Do

- Use consistent spacing and clear labels
- Provide accessible labels for screen readers
- Indicate the current item with aria-current="page"
- Use clear, plain language reflecting the real hierarchy
- Be consistent in naming, capitalisation, and punctuation
- Truncate thoughtfully, with full text available via tooltip

## Don't

- Make all breadcrumb items look the same
- Truncate without a tooltip or way to access the full text
- Rely on colour alone to indicate state

## Real token names (documentation)

- Gaps left and right between items — spacing/xs
