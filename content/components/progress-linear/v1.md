Progress indicators let people know that your screen isn't stalled while it loads content or performs lengthy operations. A progress tracker visually guides users through a series of steps required to complete a multi-step task, typically across multiple screens — it helps set expectations, reduce cognitive load, and improve task completion.

## Anatomy

- Linear — 1. Active indicator, 2. Track, 3. Stop indicator, 4. Tooltip (on hover), 5. Step
- Radial — determinate (well-defined duration, e.g. a file conversion) or indeterminate (unquantifiable, e.g. loading/syncing)

## Size

- Track/step height — 6px
- Tooltip — 36px tall, 48px wide
- Radial sizes — Small 24×24px (compact elements, buttons, form fields), Medium 48×48px (default, most use cases), Large 96×96px (prominent loading states, full-screen views)

## Typography

- Tooltip title — National 2 Medium/14px | 20px

## Behaviour

- Determinate indicators should show a consistent pace — jumping to 90% quickly then stalling on the last 10% erodes trust
- Keep progress indicators moving so people know something is still happening; if paused, give feedback explaining why
- Add a short, specific description where possible — avoid vague terms like "loading" or "authenticating" with no context
- Spinners animate in by default; use a fade-in for a smoother exit rather than a sudden snap

## Accessibility

- Use a label describing the process occurring (e.g. "loading", "submitting", "processing")
- Circular indicators don't reduce motion — a frozen spinner reads as a stopped process

<div class="apy-do">

**Do**

- Use a progress tracker when there are three or more steps
- Let people navigate by selecting a step in the sequence
- Use circular indicators for short, indeterminate activities under 5 seconds
- Simplify or split a process that needs more than six steps
- Use a "Next" button instead of a tracker if there are fewer than three steps

</div>

<div class="apy-dont">

**Don't**

- Use a linear bar loading indicator inside a button
- Switch from the circular style to the bar style mid-flow — they're different shapes and switching disrupts the interface
- Freeze a circular indicator — it can make the process look stalled

</div>
