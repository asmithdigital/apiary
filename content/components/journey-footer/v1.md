RAA's design system includes three footer types, each optimised for a specific use case: the Journey footer, the Sticky footer, and the Site footer.

## Variants

- Journey footer — contextual footer used in insurance quote journeys to guide users through steps
- Sticky footer — persistent floating footer for continuity when scrolling (not yet captured as its own component in this session)
- Site footer — informational footer used across all pages

## Anatomy

- Journey footer — hairline top divider (1px, P2/100), left-aligned primary button, optional right-aligned "Next step" text, optional right-aligned "Skip for now" text button. Desktop horizontal, pinned; mobile vertical stack, full-width button.
- Sticky footer — floating container, 1px P2/100 border, 4px radius, left-aligned primary button, right-aligned "Next step", background P3/100 at 92% opacity with 4px blur, drop shadow (0/12/48/0, P2/100 10%).

## Accessibility

- All footer content keyboard accessible in a logical flow
- Text links meet WCAG 2.1 AA contrast (4.5:1)
- Semantic HTML — &lt;footer&gt; site-wide, &lt;nav&gt;/&lt;div&gt; for sticky/journey containers
- Buttons need descriptive aria-label if text is ambiguous
- Sticky elements must not obscure key content on small screens
- Minimum touch target 44×44px

## Real token names (documentation)

- Journey footer — spacing/md padding top, spacing/md button padding L/R, spacing/sm button padding T/B, spacing/2xl+ gap to "Next: Step" text
- Site footer — spacing/md top/bottom padding, spacing/lg left/right padding, spacing/xs link-to-icon gap, spacing/md link-to-footer-text gap
- QTB footer — spacing/md throughout, spacing/2xl+ gap between button and footer text
