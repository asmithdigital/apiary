Use text area so users can enter multiple lines of text. Text area is used when information longer than a single line of text is needed or expected — for example, comments fields.

## Variants

- Default, invalid

## Anatomy

- Label
- Container
- Text (optional)
- Description (optional)
- Character count (optional)

## Size

- 6px spacing between label, container and description
- 16px padding in the container

## Typography

- Default — Label Medium/14px|20px P2/100; Text Regular/14px|20px P2/100; Description Regular/12px|18px P2/50; Character count Regular/12px|18px P2/50
- Invalid: Invalid/100. Valid: Valid/100. Disabled: P2/40.

## Character limit

- Only use a character count when there's a good reason — legal, technical, or evidence users will give more text than needed

## States

- Default, active, hover, focus, disabled

## Transitions

- Animation on active and focus states

## Arrangement & spacing

- 24px margin between the text area and nearby components
- Text area container should fill the width of its parent
- Right-align the character count

## Accessibility

- Avoid placeholder text where possible — it disappears once typing starts, isn't always read by screen readers, and often lacks contrast
