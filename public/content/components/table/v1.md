Tables display structured data in rows and columns for easy comparison and scanning. In a design system, they should be clear, accessible, and responsive, with consistent spacing, readable text, and support for sorting, filtering, and pagination when needed.

## Anatomy

- Clear headers, aligned columns, and consistent cell spacing. Header rows carry labels, with optional sorting or tooltips. Rows support scanning, selection, or actions.
- 1. Label, 2. Title, 3. Paragraph, 4. External link with icon, 5. Paragraph details, 6. Table Container

## Behaviour

- Hover/focus states for clickable rows; prefer buttons/links within cells over full-row clicks
- Sorting with visible icons; dynamic filtering with clear feedback
- Expandable rows for inline detail; pagination or lazy loading with loading indicators and result counts
- Helpful messages for empty/error states
- External links clearly labelled (e.g. with a ↗ icon), open in a new tab with target="_blank" and rel="noopener noreferrer"

## Types

<dl class="apy-deflist">
<dt>Bordered table</dt><dd>spacing/md (24px) padding, 1px solid border using the P2/100 colour token, 4px radius. Best for compact layouts, cards, or modular components where the table should be visually distinct from surrounding content.</dd>
<dt>Divider table (borderless)</dt><dd>spacing/md (24px) padding, no outer border/radius, a 1px P2/50 divider between stacked tables/sections. Best for clean, open layouts like dashboards or lists.</dd>
</dl>

## Accessibility

- Semantic table elements — &lt;table&gt;, &lt;thead&gt;, &lt;tbody&gt;, &lt;th&gt;, &lt;td&gt;
- Descriptive headers using &lt;th scope&gt; to link data cells to their headers
- Keyboard navigation through rows and interactive elements (sorting, pagination)
- Sufficient colour contrast; never rely on colour alone
- Captions or summaries for scrollable/complex tables

## Content guidelines

<dl class="apy-deflist">
<dt>Be clear and concise</dt><dd>Short, descriptive column headers — not vague terms like "Info" or "Data".</dd>
<dt>Keep labels simple</dt><dd>Plain language; only universally-understood abbreviations.</dd>
<dt>Align text properly</dt><dd>Left-align text, right-align numbers for easy comparison.</dd>
<dt>Use consistent formatting</dt><dd>Same date format, currency symbols and decimals throughout.</dd>
<dt>Limit text length</dt><dd>Truncate with ellipses; use tooltips or expandable rows for more detail.</dd>
<dt>Avoid overloading</dt><dd>Prioritise essential content; use progressive disclosure for secondary info.</dd>
<dt>Support empty states</dt><dd>e.g. "No items found. Try adjusting your filters."</dd>
</dl>
