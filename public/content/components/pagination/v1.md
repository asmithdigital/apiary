Pagination breaks content into pages for easier navigation. Include clear page numbers, next/previous buttons, and highlight the current page. Ensure it's accessible with keyboard support and aria-labels. Use when users need to browse or return to specific content easily.

## Anatomy

- Pagination includes previous/next buttons, page numbers with the current page highlighted, and optional ellipses or first/last buttons. Elements are evenly spaced in a container.
- 1. Previous Button, 2. First Page Number, 3. Ellipsis, 4. Next Button, 5. Pagination Bar

## Size

- Internal padding: 11px top, 13px left, 11px bottom, 13px right

## Typography

- Previous page — Font Awesome 6 Pro/14px | 20px
- Page number — Regular/14px | 20px
- Ellipsis — Regular/14px | 20px
- Next page — Font Awesome 6 Pro/14px | 20px

## Behaviour

- Dynamic updates — content updates immediately on page selection
- Disabled states — Previous/Next disabled when not applicable (first/last page)
- Visible feedback — current page highlighted with background colour P2/30
- Smooth, fast transitions
- Keyboard and touch-friendly controls

## Types

<dl class="apy-deflist">
<dt>Pagination</dt><dd>Divides content into multiple pages, typically with page numbers or Previous/Next buttons, helping users navigate large datasets or articles in manageable sections.</dd>
<dt>Pagination (Previous and next icons only)</dt><dd>Shows only two icons for moving between pages — good for mobile or minimalist designs, and linear content like articles or image galleries where exact page numbers aren't necessary.</dd>
</dl>

## Accessibility

- Keyboard navigation (Tab, Enter, arrow keys) and screen reader support
- Semantic HTML — &lt;nav&gt; with aria-label="Pagination", &lt;ul&gt; for structure
- Current page indicated with aria-current="page"
- Clear aria-labels on buttons/links (e.g. "Go to page 3")
- Visible focus states; large enough touch targets

{{> do-dont}}

## Content guidelines

<dl class="apy-deflist">
<dt>Show the current page clearly</dt><dd>Different colour, bold text, or background highlight, plus aria-current="page" for screen readers.</dd>
<dt>Include Previous and Next buttons</dt><dd>Disable them when not needed (first/last page) to avoid confusion.</dd>
<dt>Use ellipses for long lists</dt><dd>Collapse the middle pages to reduce visual clutter while showing more exist.</dd>
<dt>Keep page numbers clickable</dt><dd>Let users jump directly to a page rather than clicking through sequentially.</dd>
<dt>Support keyboard navigation</dt><dd>Tab, Enter, and arrow keys should all work.</dd>
<dt>Use descriptive ARIA labels</dt><dd>e.g. aria-label="Go to page 4".</dd>
<dt>Design for responsiveness</dt><dd>Simplify controls on smaller devices without losing usability.</dd>
<dt>Avoid overloading with too many pages</dt><dd>Limit visible page links to keep the experience user-friendly.</dd>
</dl>
